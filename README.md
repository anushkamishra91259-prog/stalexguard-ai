## 🌟 Executive Summary

Large Language Models (LLMs) suffer from fixed knowledge training cutoffs, leading to catastrophic knowledge obsolescence and subtle hallucinations when deployed in production. Standard evaluation systems only measure lexical or embedding consistency against static vector databases, failing completely when facts evolve in the real world.

**StaleGuard.AI** provides continuous semantic verification by calculating **temporal half-life decay**, detecting **chronological drift**, and cross-referencing multi-source authoritative consensus before answers reach users or enterprise workflows.

## 🚀 Live Demo & Zero-Build Architecture

This application is built with a **production-grade zero-build self-contained architecture**.
No Node compilation, no Webpack/Vite overhead, and zero backend server setup required.

- **Local Preview**: Open `index.html` directly in any web browser or via local HTTP server (`http://localhost:8000`).
- **Production Edge Hosting**: Fully compatible with Vercel Static Edge (`cleanUrls: true`, `rewrites`).

## ⚡ 11 Core Enterprise Modules

### 1. 📊 Executive Overview Dashboard
- High-level KPIs: Total Audited Claims, Verified Fresh %, Stale Temporal Drift %, Hallucination Rate, and Mean Interception Latency (~180ms).
- Dynamic Chart.js visualizations: 30-Day Knowledge Degradation Velocity and Claim Classification Doughnut.
- Real-time audit activity stream.

### 2. ⚡ Freshness Checker (Core Inspection Engine)
- Flexible input console supporting arbitrary statements, strictness thresholds, and temporal drift horizons.
- Multi-step diagnostic scan HUD with animated progress indicators.
- Radial circular SVG freshness gauge (0–100%) with status badges.
- Semantic Claim X-Ray dissecting named entities and decay half-lives.
- Ground truth side-by-side diff comparing stale claims with contemporary 2026 reality.

### 3. 🧪 Advanced Hallucination Testing Lab
- Adversarial A/B testing playground comparing multiple candidate LLM responses side-by-side.
- Entity swap & temporal trap detection with granular scoring deltas.

### 4. ⏳ Real-Time Knowledge Timeline
- Interactive chronological lifecycle tracing when facts were first established, inflection points (e.g. *The Merge*, acquisitions, leadership changes), and obsolescence timestamps.

### 5. 🌐 Source Intelligence Panel
- Authoritative ground-truth registry manager tracking domains (SEC EDGAR, Ethereum Foundation, NASA Astrobiology, Reuters, W3C).
- Real-time endpoint ping simulation, uptime monitoring, and consensus validation.
- Modal to connect custom authoritative endpoints.

### 6. 🛰️ Knowledge Drift Monitoring
- Autonomous domain watchdogs tracking knowledge decay half-lives:
  - *Frontier AI Models* (Half-life: 2.1 months)
  - *Corporate Leadership* (Half-life: 4.2 months)
  - *Blockchain Consensus* (Half-life: 6.8 months)
  - *Geopolitical Heads of State* (Half-life: 14.0 months)

### 7. 📦 Batch Verification Suite
- Enterprise multi-claim ingestion console supporting multi-line entry and CSV/JSON dataset uploads.
- Sortable and filterable bulk results table with one-click Batch CSV export.

### 8. 🚨 Intelligent Alert Center
- Real-time notification inbox categorizing high-risk temporal drift, contradictory evidence, and source updates.
- Notification popover with unread counter badges and severity filters.

### 9. 📈 Analytics & Drift Kinetics
- Empirical telemetry analytics graphing guardrail interception latencies and domain-specific drift vulnerability radar charts.

### 10. 📑 Compliance Reports & Export Archive
- Comprehensive audit archive with searchable records.
- Executive print-ready PDF styling with cryptographic verification signatures.
- One-click structured JSON and CSV report downloads.

### 11. ⚙️ Settings & Workspace Controls
- Configurable strictness thresholds, drift tolerance parameters, custom Graph-RAG endpoint connectors, and one-click demo data reset.
